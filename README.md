# Forza-AFK-Loop
Create by LennyS


Deutsch

Forza AFK Loop

Ein einfaches Automations-Tool für wiederkehrende Rennabläufe in Forza Horizon.

Das Programm übernimmt wiederholende Eingaben im Spiel und sorgt dafür, dass Rennzyklen automatisch neu gestartet werden. Dadurch können Abläufe im Hintergrund stabil weiterlaufen, ohne manuelle Steuerung.

Mit einer übersichtlichen Oberfläche, Hotkey-Steuerung und flexiblen Einstellungen lässt sich das Tool schnell anpassen und direkt nutzen.

Features:

Automatisches Wiederholen von Rennabläufen
Einfache Start/Stop-Steuerung
Benutzerfreundliche GUI
Anpassbare Hotkeys und Einstellungen
Läuft stabil im Hintergrund

English

Forza AFK Loop

A simple automation tool for repetitive race cycles in Forza Horizon.

The program handles recurring in-game inputs and automatically restarts race loops, allowing continuous progression without manual control.

With a clean interface, hotkey support, and flexible settings, the tool is easy to use and quick to set up.

Features:

Automatic race loop repetition
Simple start/stop control
User-friendly GUI
Customizable hotkeys and settings
Stable background operation
